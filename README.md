# MeshWeaver 
Zero-dependency decentralized async task broker for edge computing.

## Project Goal
MeshWeaver is a pure Python peer-to-peer async task execution framework that avoids Redis, RabbitMQ, and any central coordinator.

## Planned Features
- Peer discovery using asyncio
- Gossip-based CPU/RAM sharing
- Load-aware task scheduling
- Distributed task execution
- Automatic task reassignment on node failure
